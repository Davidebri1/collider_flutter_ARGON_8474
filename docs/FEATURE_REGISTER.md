# Feature Register

A feature exists only if it has a row here. Status is proven by the After image, never by a sentence.

| Feature | Use case | Expected outcome | Appears when | Reference |
| --- | --- | --- | --- | --- |
| Pinned prompt | Ask all models at once | Condensed prompt sits above the nav bar, visually tied to the ticker above it | Always | message bar, chat box |
| Composer | Write a considered prompt | Tap the prompt, it expands with every composer capability previously built; compose button is clear, animated on press and on transition | On tap | message bar, chat box |
| Model ticker | Compare model answers at a glance | Colour-coded cards per model with real hierarchy, newest highest in elevation; no line-and-border clutter | After a prompt | colour elevation, conversations, Nimo cards |
| Research depth | Get the depth of answer the question deserves | Internet: a regular response. Research: a report. Deep research: an annotated paper with more insight and no jargon | Selected in the composer | |
| Browser | Open a source without leaving | A real page loads, back and forward work, escapes in one gesture | On link tap | internet browser |
| Music widget | Keep a track playing while working | Placeable anywhere by drag and drop, stays where placed | On play | premium detail |
| Theme Gallery | Choose a free look | Free themes only | From nav | |
| Premium Theme Market | Choose a live wallpaper | Swipe up from the Gallery; live wallpapers play smoothly and are sourced properly | Swipe up | premium detail |
| Smart Gen | Plan generation work | Colour-coded, flexible cards on a board, placeable, editable in line | From nav | Nimo kanban |
| Apps | Jump to a tool | Icons that match the glass language | From nav | frosted icons |
| Consequential toggles | Control privacy and persistence | Incognito, autosave consensus result, Smart Gen personal information access | Where the consequence applies | autolayout menu |
